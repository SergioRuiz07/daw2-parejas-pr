# Retro Arcade Cup 2026

Bienvenido al repositorio oficial del torneo **Retro Arcade Cup 2026**.

## Descripción del Proyecto
Este proyecto es la plataforma web para consultar el programa completo del torneo de arcade y los partidos de la Retro Arcade Cup 2026. Permite ver los horarios de cada jornada y que los jugadores se inscriban al torneo mediante un formulario. Se ha desarrollado en equipo, usando ramas, issues y Pull Requests en GitHub.

## Tecnologías Utilizadas
- HTML5
- CSS3 (Estilo arcade / neón)
- Git & GitHub (Flujo de trabajo colaborativo)

## Estructura del Proyecto
- `index.html`: Página principal de bienvenida.
- `programa.html`: Horarios y torneos de la jornada.
- `inscripcion.html`: Formulario para jugadores.
